Eight PlayTrain environments, each generated as a single JavaScript file from a prompt. Both trained policies are shown per game, argmax on the human study's seeds, captioned with the mean greedy return over six episodes; the stronger one is outlined. Each clip is one whole episode, replayed frame for frame, ending where the episode did — often at the study's 2000-step cap rather than at a death. Under each pair is the training run those two policies came from, over the first 100M environment steps, with its own y-axis. Those curves are sampled-policy returns, so they do not equal the greedy scores above them.

Abstract

While many video-game environments (VGEs) have played crucial roles in advancing reinforcement learning (RL), developing novel VGEs or modifying existing ones to support new features has been a laborious process requiring extensive hand-coding. Here we present PlayTrain, an RL framework that combines the abilities of large language models (LLMs) to robustly generate JavaScript (JS) games from a minimal human prompt, and an efficient pipeline that can run any JS game in a standard gym environment. Not only are recent LLMs particularly good at writing JS code, but the JS format also allows users to easily play generated VGEs, while PlayTrain enables us to train RL agents on the exact same games. We demonstrate multiple use cases of PlayTrain, including cloning well-known Atari and ProcGen games in simple JS, where PlayTrain trains pixel-based agents end-to-end at over 0.9M agent-decisions per second on a single GPU node; and creating modified versions thereof (e.g., that support novel test sets, procedural generation logics, or game dynamics). Through PlayTrain, we reimagine RL VGE development: all we need is a single JS file, generated and modified through an LLM. We discuss promising future RL research directions that PlayTrain unlocks.

Trained agents across the catalog

Every environment, with the best IMPALA and the best PPO checkpoint side by side. Clips are each trainer's best of six argmax episodes; captions give the mean greedy return over those six, which is the metric the two are ranked on, since their training curves come from different behaviour policies and are not comparable. Across the 34 games PPO takes 17, IMPALA 14, and three are exact ties. Games neither trainer solves are left in. Two entries are newer arrivals, trained after the rest: downwell_fresh.refined is the reworked version of that game, and vvvvvv.v2 a fork whose gravity and entity sizes changed — on that one neither trainer beats random play, on any of three seeds, even trained directly on it. Both keep their originals above rather than replacing them.
