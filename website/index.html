PlayTrain: An Efficient Reinforcement Learning Framework for LLM-Generated Adaptable JavaScript Games

1Harvard University 2MIT, Brain and Cognitive Sciences 3Kempner Institute 4Yale University

Trained agents playing eight PlayTrain environments, each generated as a single JavaScript file from a prompt. Each clip is the stronger of that game's two policies, argmax, on the human study's seeds, replayed through the headless engine frame for frame.

Abstract

While many video-game environments (VGEs) have played crucial roles in advancing reinforcement learning (RL), developing novel VGEs or modifying existing ones to support new features has been a laborious process requiring extensive hand-coding. Here we present PlayTrain, an RL framework that combines the abilities of large language models (LLMs) to robustly generate JavaScript (JS) games from a minimal human prompt, and an efficient pipeline that can run any JS game in a standard gym environment. Not only are recent LLMs particularly good at writing JS code, but the JS format also allows users to easily play generated VGEs, while PlayTrain enables us to train RL agents on the exact same games. We demonstrate multiple use cases of PlayTrain, including cloning well-known Atari and ProcGen games in simple JS, where PlayTrain trains pixel-based agents end-to-end at over 0.9M agent-decisions per second on a single GPU node; and creating modified versions thereof (e.g., that support novel test sets, procedural generation logics, or game dynamics). Through PlayTrain, we reimagine RL VGE development: all we need is a single JS file, generated and modified through an LLM. We discuss promising future RL research directions that PlayTrain unlocks.

Every environment, with the best IMPALA and the best PPO checkpoint side by side. Clips are each trainer's best of six argmax episodes; captions give the mean greedy return over those six, which is the metric the two are ranked on, since their training curves come from different behaviour policies and are not comparable.
