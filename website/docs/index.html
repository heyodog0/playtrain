Introduction

PlayTrain

LLM-generated 2D game environments and a headless reinforcement-learning runtime for Gymnasium.

PlayTrain turns a self-contained JavaScript game into two things at once: a game a person can open in a browser and an environment an agent can train against without a browser. The package includes the runtime, a game catalog, generation tools, and a validation contract.

Core workflow

Install the runtime, open a bundled game, step it through Gymnasium, and move to vectorized environments when you are ready to train.

Highlights

  • Run p5.js and Matter.js games as Gymnasium environments.
  • Use an embedded QuickJS engine and native rasterizer without a DOM or browser.
  • Step many independent environments through NativeVecEnv.
  • Generate and modify games from natural-language descriptions.
  • Validate observation shape, actions, determinism, throughput, and episode bounds.

Installation

PlayTrain requires Python 3.11 or newer, Node.js 18 or newer, a C/C++ toolchain, Rust, uv, pnpm, and just. The bootstrap script installs uv, pnpm, and just when they are missing.

git clone https://github.com/heyodog0/playtrain
cd playtrain
./bootstrap.sh
just install
just test

just install installs the JavaScript and Python dependencies and builds the native QuickJS backend used by the default runtime.

Run your first environment

GameEnv is the default single-environment API. It follows the familiar Gymnasium reset and step interface.

from playtrain.runtime import GameEnv

env = GameEnv(game="flappy_bird")
obs, info = env.reset(seed=0)

for _ in range(1000):
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        obs, info = env.reset()

env.close()

Observations are (64, 64, 3) RGB arrays. Bundled games use the shared eight-action discrete space.

Play in the browser

The same source file can be played directly. Open the project’s browser game picker:

just play flappy_bird

You can also use the playable catalog on the project page without installing anything.

Train with vectorized environments

Use NativeVecEnv when a trainer needs many environments. It hosts N QuickJS environments on an in-process C++ thread pool.

from playtrain.runtime import NativeVecEnv

envs = NativeVecEnv(
    game="coinrun",
    num_envs=64,
    autoreset=True,
)

Training implementations and example configurations live in the playtrain-trainers repository.

Generate a variant

Generation needs a Gemini API key. Runtime and training do not.

export GEMINI_API_KEY=...

uv run playtrain-variant \
  --parent breakout \
  --prompt "3 simultaneous balls, lost balls cost a life" \
  --name breakout.multi

uv run playtrain-validate --game breakout.multi
just play breakout.multi
