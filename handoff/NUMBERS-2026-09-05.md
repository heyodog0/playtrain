# Canonical numbers for the paper — provenance table (2026-09-05)

**This file is the single source of truth for what goes in the paper.**
`HANDOFF-2026-09-05-tier-cascade.md` is a 1,500-line chronological journal and
contains superseded values; when the two disagree, THIS file wins. Anything not
listed here is not final.

All jobs ran unpinned. "Same-job" means both arms measured in one allocation, so
ratios are node-independent even where absolutes are not.

## Figure 4A — env-only scaling, geomean env steps/s

Binary **tier3**. Seven thread points, all arms same node (holy8a28510).
Jobs 44545120 (PlayTrain) + 44601287 / 44614598 (EnvPool tuned, corrected).

ProcGen16, 10/20/40/80 threads:
- PlayTrain tier3: 453,493 / 909,788 / 1,812,814 / **3,642,545**

- EnvPool as-shipped: 178,217 / 278,042 / 417,106 / **468,997**

ALE8 @80: PlayTrain **7,355,750**, tuned **350,601**, as-shipped 238,829.

**Ratios (USE THESE — 2.58x and 20.98x are superseded, they were cross-node):**

| threads | 10 | 20 | 30 | 40 | 60 | 80 |
|---|---|---|---|---|---|---|
| ProcGen | 1.28x | 1.55x | 1.75x | 1.95x | 2.28x | **2.57x** |
| ALE | 20.11x | 20.59x | 20.52x | 20.59x | 20.59x | **20.59x** |

PlayTrain scales 2.01/1.99/2.01 per doubling (100% efficiency at all 7 points);
EnvPool tuned ProcGen 1.65/1.59/1.52, falling to **50% efficiency at 80 threads**;
EnvPool tuned ALE holds **96%**.

**ProcGen is a scaling story, ALE is a constant-factor story.** They are
different mechanisms and must not be collapsed into one clause.

**FOOTNOTE REQUIRED:** EnvPool's BossfightEasy reads 78,149 at 80 threads, ~20x
below every other ProcGen game (a 129x ratio). Not our measurement error — the
same value is in published-era data. But it lifts our ProcGen geomean: excluding
it pulls the 80-thread ratio from 2.57x toward ~2.1x. Footnote it rather than
letting a referee find it.

## Owed to the paper, not just number swaps

1. **The tier sentence.** Every Fig 4A / B / C / D number comes from the
   compile-at-load AOT path, which the text does not currently mention (the
   commented-out draft was deleted in an Overleaf pull). Supportable claim: a new
   game gets tier 2 immediately and tier 3 about a minute later, bit-exact, same
   PGO increment as the paper games; gain scales with the game's engine share,
   1.05-2.1x, geomean 1.19/1.30 on nine held-out games.
2. **The bossfight footnote** (above).
3. **The validation gap**, belongs in methodology or limitations: every gate the
   tier adoption passed exercised the SYNC path; the fork host's async entry
   point was never run at all. That is how a 6x regression reached the headline
   table.
4. **Panel A design decision** — two-arm (as-shipped + tuned) vs tuned-only.
   Previews at `handoff/fig_preview_2026-09-03/`. Legend should read "EnvPool
   (tuned)", with the documented-settings provenance in the caption — EnvPool
   publishes no ProcGen benchmark at all, so "documented best" invites
   "documented where?".
