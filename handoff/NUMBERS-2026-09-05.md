# Canonical numbers for the paper — provenance table (2026-09-05)

**This file is the single source of truth for what goes in the paper.**
`HANDOFF-2026-09-05-tier-cascade.md` is a 1,500-line chronological journal and
contains superseded values; when the two disagree, THIS file wins. Anything not
listed here is not final.

All jobs ran unpinned. "Same-job" means both arms measured in one allocation, so
ratios are node-independent even where absolutes are not.

**The paper is now ONE binary.** Table 1(a) was measured under adv2 only as a
workaround for the AOT host's double-buffered regression; that regression was
diagnosed and fixed on 2026-09-05 (handoff §0 — envs are pinned to an owner
worker for life, killing the glibc arena convoy), and Table 1(a) has been
re-measured under the fixed tier 3. Every row came out at or above adv2, so the
workaround is retired.

**The disclosure sentence is DELETED, not reworded.** It used to read
"environment-only results use the AOT engine tiers; trainer-attached results use
the interpreter build, because the AOT host's double-buffered path has an
unresolved regression." There is no longer a split to disclose. What DOES still
belong in the paper is the validation-gap note (§"Owed to the paper" item 3) —

**Do not quote the "vs adv2" column as a speedup.** Those ratios are UPPER

claim is PARITY OR BETTER under the trainer, not a gain. The trainer is
learner-capped — that is exactly why the 6x environment regression was invisible

show up as a proportional training gain here.

**Degraded node `holygpu8a15203`.** Both arms ran unpinned, and this one node

would have read as a false regression. Every task that ran on it was re-measured
with `--exclude=...,holygpu8a15203`; the re-runs landed on eight different nodes
and agree with the same row's other nodes. The uncleaned values are listed as
superseded below. **Anything unpinned on kempner_h100 needs this check.**

SUPERSEDED, do not use: 1,005,870 / 347,722 / 176,081 / 65,978 (the adv2 rows —

   tier adoption passed exercised the SYNC path; the fork host's async entry
