## 3. Factual corrections established this session — do not let the prose regress

These were each caught in draft prose at least once; they are the likely
regressions:

1. **Compiled once per machine; environments are only instantiated.** Games are
   never compiled — read as data, interpreted. Main text ~364 "compile directly
   into each PlayTrain environment" is the misreading to correct, not echo.
2. **Frozen math ≠ draw-call identity.** Vendored fdlibm/openlibm (`fm_*`)
   governs the GAME's `Math.sin/cos/pow/atan2` (platform libms differ by ULPs;
   results, not "math standards"). Drawing-geometry identity comes from the
   rasterizer-internal `psin`/`pcos` polynomial pair (identical constants in
   `lib.rs` and `raster.mjs`). Two tiers; games can't observe the polynomial
   through `Math.*`. Main text ~396 ("implements its own sin and cos") must end
   up consistent with this.
3. **Humans play on the pure-JS rasterizer** (`raster.mjs`), not wasm: browser
   tester inlines raster.mjs + p5-shim (`play-templates.mjs:39-53`); Node
   defaults to wasm with JS fallback (`p5-shim.mjs:15-16`); gate reference =
   V8 + wasm. Two implementations (JS = spec, Rust = port), three deployments
   (native / wasm / browser-JS). node-canvas contributed only the interface +
   BGRA-premult buffer format; raster.mjs replaced it, not derived from it.
4. **No anti-aliasing, by construction**: binary center-sampled coverage
   (`raster.mjs:137` "scanline, nonzero winding, sample at row center y+0.5"),
   nearest-neighbor blits (line 63). Framing that survives review: third-party
   AA is where renderers stop being reproducible; hard edges make bit-exactness
   cheap — NOT "AA is impossible deterministically".
5. **Step-loop order**: input → draw() → rasterize into obs buffer (the
   rasterizer's buffer IS the obs buffer, not "identical to") → reward = score
   delta + terminal read. Reward comes AFTER draw.
6. `\texttt{qjs_host}` needs the underscore escaped (`qjs\_host`) — this
   exact typo was in a draft.
7. Open citation: "previous work involving JS RL runtimes uses it
   \citep{TODO}" — needs a real cite; also "runtimes" is an advisor-flagged
   word (main text at least).
